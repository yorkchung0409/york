# 德州保险盈利计算器

这是一个纯静态 PWA 项目，不需要 Node.js、数据库或后端服务。部署时把整个目录上传到任意支持 HTTPS 的静态托管服务即可。

## 文件说明

- `index.html`：页面结构和 iOS PWA 配置
- `styles.css`：页面样式和移动端布局
- `poker-core.js`：无 DOM 的赔率、牌力和主池/边池核心计算
- `app.js`：页面状态、输入校验、单次/双次保险和结果渲染
- `manifest.json`：PWA 应用名称、图标和启动方式
- `service-worker.js`：离线缓存
- `icons/`：iOS 和 PWA 应用图标

页面内可以切换“一次保险”“两次保险”和“胜率和赔率”。两次保险先计算转牌；转牌未爆后可选择实际转牌，或在手工模式点击“转牌未爆，进入河牌”，再计算河牌 outs。河牌阶段解锁前，赔率刻度、买入和快捷比例均不可操作。主池/边池模式会按每个独立池显示可保金额、outs、赔率和买入上限；当 outs 有效时，买入栏会默认填入覆盖可保金额的建议值，手动改过的金额会保留。

边池结果会把每个玩家实际进入的底池逐池展开，明确列出每种情形的概率、买入、实收和净盈亏，同时汇总全押投入、实际入池金额、退回金额、计划保险买入、最差/最好边界、期望净盈亏，以及不买保险的对照值。没有领先的底池也会显示为“未计翻盘”，不会从总投入中被遗漏。

牌面与手牌区域支持选择 2～4 人、翻牌/转牌/河牌公共牌和每位玩家的两张手牌。选牌器会阻止重复牌；非法或重复的隐藏输入会显示错误状态。完成选牌后点击“计算 outs 并填入保险”，系统会按实际已知牌数计算下一张牌的获胜、平局和保险/翻盘 outs，并把结果写入对应保险区。主池/边池模式可以按已选手牌自动更新牌力排名，手动修改排名后会保留手动结果。当前输入、边池字段和牌面会自动保存在本机，点击重置会清除草稿。

“胜率和赔率”从个人 call 视角计算跟注前底池、本次跟注、底池赔率、有效 outs 命中率、实际 equity 和 Call EV。手动 outs 默认按翻牌后 47 张、转牌后 46 张未知牌计算；自动 equity 会扣除所有已知公共牌和手牌，完整对手手牌使用精确枚举，未知对手座位使用固定样本估算。当前结论以看到下一张牌为主，到河牌概率和四二法仅作为参考。

## 部署要求

1. 上传整个项目目录，保留 `icons/` 子目录结构。
2. 确保网站使用 HTTPS。
3. 确保网站根路径可以直接打开 `index.html`。
4. 部署完成后，用 iPhone Safari 打开网址，选择“分享”→“添加到主屏幕”，并开启“作为 Web App 打开”。

## 本地预览

如果需要本地预览，可以在项目目录运行任意静态文件服务器，例如：

```bash
python -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

## 测试

核心回归测试可直接打开 `tests.html`，不依赖 Node.js 或后端服务。使用本地静态服务器时访问 `http://127.0.0.1:4173/tests.html`，确认页面显示全部测试通过。

提交前可用 Node.js 做语法检查：

```bash
node --check poker-core.js
node --check app-hand-analysis.js
node --check app.js
node --check service-worker.js
```

当前 PWA 缓存版本为 `81`，升级静态资源后需重新加载页面，让 Service Worker 安装新缓存；离线回退只对页面导航生效，脚本、样式和图标请求失败不会返回 HTML。
